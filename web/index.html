How it works

It shows you. Then it makes you do it.

Tutorials happen on someone else's screen. Agents that just do the task leave you no better at it. Ghost Hands does both halves.

1

Ask

Hold F8 and say it, or press F7 and type it. "How do I make a bar chart of sales by month?"

2

The ghost does it

A glowing cursor glides to each real target at human pace, clicks and types there, and narrates every step with a caption and a calm voice.

3

Your turn

Press F9. Pulsing rings mark each step. It waits for your real click: hits turn mint, misses shake, and after two misses the ghost shows you again.

4

It never does the scary part

Send, Pay, Delete, Submit: it stops with an amber lock and says "That one is yours." Grab the mouse any time to take over.

Built on OpenAI

It reads pixels, not APIs.

So it works in any app on your screen. The loop runs on GPT-6.1 Sol with the computer-use tool in the Responses API.

01 · seeScreenshotmss capture, scaled to 1440 px wide, overlay excluded
02 · thinkGPT-6.1 Soltools=[{"type":"computer"}] returns a computer_call with ordered actions and commentary
03 · checkGuardUI Automation name under the point. Send, Pay, Delete? Stop.
04 · showGhost glidesCaption from the commentary, voice from TTS, then the real click
05 · logRecordsteps.json, target crops and cached voice for replay and coaching
New screenshot goes back as computer_call_output until there is no computer_call left.
ActGPT-6.1 Sol + computer use

Responses API, ordered action batches, screenshots as computer_call_output. Its commentary becomes the captions.

Listengpt-transcribe

Push-to-talk speech-to-text with keyword hints, so a noisy room still gets the task right.

Speakgpt-4o-mini-tts · marin

Streamed and steered to a "calm, friendly teacher". Each line is cached so replays need no network.

  • Invisible to the model. The overlay uses WDA_EXCLUDEFROMCAPTURE, so the AI never sees the ghost. That needed a GL-composited window, because the flag fails on layered windows.
  • Click-through, never steals focus. A transparent, no-activate tool window. Your app keeps the keyboard the whole time.
  • 60 fps on a laptop iGPU. PyQt6 with prebaked glow pixmaps, cubic-eased arcs and a 22-point comet trail.
  • Clicks land exactly. Per-monitor DPI aware, so coordinates line up at 125% and 150% scaling.
  • Crash-proof UI Automation. The accessibility probe runs in an isolated helper process.
  • Offline safety net. F10 replays the last run exactly, with zero AI calls.

Built in a day with Codex and Claude Code working in parallel: one on the brain, one on the overlay.

Set up

Windows 10 / 11Python 3.11+OpenAI API key
> git clone https://github.com/Arham-Begani/ghost-hands
> cd ghost-hands
> pip install -r requirements.txt
# .env
OPENAI_API_KEY=sk-...
> python main.py
No key? python main.py --fake runs a scripted demo of the whole overlay with no API calls.

Hotkeys

F8 holdTalk. Say the task, release to run.
F7Type the task instead. Good for noisy rooms.
F9Your turn. Coach me through the last run.
F10Replay the last run. No AI calls.
EscStop everything.
Move mouseTake over mid-run.

Safety

The irreversible click is always yours.

Safety lives in code, not in a prompt the model could talk its way around.

  • Hard stop before every clickIt reads the UI Automation name under the pointer and refuses Send, Pay, Delete, Submit, Post, Buy, Transfer and friends.
  • Grab the mouse, it lets goAny deliberate move freezes the run instantly: the ghost dissolves and says "You've got it ✋".
  • Human pace on purposeYou can't learn from a blur, and you can always see what it's about to do.
  • Model safety checks are never auto-acknowledgedA pending safety check hands control back to you and ends the run.
